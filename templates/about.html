About This Project

Multi-Factor Prediction of Rice Yield Using Agronomical Factors

Project Overview

This is a college AI/ML project that predicts rice crop yield using multiple agronomical factors and machine learning regression models.

Rice is one of the world's most important food crops, feeding over 3 billion people. Accurate yield prediction enables better agricultural planning, optimises resource use, and supports food security initiatives.

The system trains four regression models on user-provided agricultural data, automatically selects the best-performing model, and uses it to predict rice yield from new input values.

ML Methodology
Data Leakage Prevention

All preprocessing (imputation, scaling) is fitted exclusively on training data. The test set is only used for final evaluation — never for tuning or cross-validation.

Cross-Validation

5-fold cross-validation is performed within the training set to give stable performance estimates without touching the final test split.

Hyperparameter Tuning

RandomizedSearchCV is used for Random Forest and XGBoost, exploring a reasonable grid of hyperparameters efficiently.

Model Selection

The best model is chosen automatically by highest R² score on the held-out test set. No manual selection or result manipulation.
